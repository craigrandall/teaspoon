# Microsoft specifications as normative format authority

## Decision

Use Microsoft's Open Specifications as the normative authority for PST/MSG interpretation.

Primary specifications:
- MS-PST
- MS-OXMSG
- MS-OXCMSG
- MS-OXOMSG
- MS-OXPROPS

Independent implementations are evidence and validation oracles, not normative authorities.
